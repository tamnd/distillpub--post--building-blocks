# Những Viên Gạch Nền Tảng của Khả Năng Diễn Giải

Bản dịch tiếng Việt của bài Distill `The Building Blocks of Interpretability`.

## Mở cục bộ

Chạy từ thư mục repo:

```bash
python3 -m http.server 8000
```

Sau đó mở `http://localhost:8000/public/index_vi.html`.

Không mở trực tiếp file HTML bằng `file://`, vì trang tải hình, dữ liệu tương tác và JavaScript qua HTTP.
